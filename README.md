Velvet Vault is an original top-down stealth heist game for make.fun's best-heist-game-20261122-0559 bounty. Wren robs the Halden Gallery across 3 rooms: patrolling guards with vision cones and suspicion meters, sweeping security cameras, the glowing Argent Star loot target, and an alarm meter that triggers LOCKDOWN at 100%.

Tools cost charges: noise coin (lures guards), smoke puff (hides the thief), EMP burst (kills cameras). Controls: WASD/arrows to move, Shift sneak, Space sprint, Q/E/R tools, P pause. Original synthesized WebAudio sounds, no assets, no network.

Play: serve `game/` with any static HTTP server and open `index.html` in desktop Chrome.
